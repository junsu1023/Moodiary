# Moodiary
AI를 통해 오늘의 일기를 분석하여 음악, 글귀를 추천해주는 안드로이드 애플리케이션

# Tech Stack
- Language: Kotlin
- UI: Jetpack Compose, Material3
- Architecture: Clean Architecture, MVVM, MVI
- DI: Hilt(Dagger)
- Async: Coroutines, Flow
- Network: Retrofit2, OkHttp3, Kotlinx Serialization
- BackEnd/DB:
  - Firebase Authentication(로그인/회원가입)
  - Firebase Firestore(일기 데이터 저장)
  - DataStore Preferences: 로컬 설정(다크 모드) 저장
